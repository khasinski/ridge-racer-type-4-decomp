# Hand-written assembly in the PAL main EXE (splat segment type `hasm`).
# These functions are linked from splat-generated asm (asm/ is not tracked) and are
# excluded from the C-coverage denominator. Only certain cases are listed, i.e. code
# no stock gcc (2.7.2, 970318, 2.8.1) can emit from C:
#   trapping-arith  add/addi/sub/neg (gcc only emits addu/addiu/subu/negu)
#   cop0            mfc0/mtc0/rfe
#   syscall         syscall instruction
#   k0k1            uses kernel registers $k0/$k1
#   store-at        stores the assembler temporary $at to memory
#   shared-entry    has an interior label entered by jumps from other hand-written
#                   functions (C cannot expose a mid-function entry point)
#   tail-jump       frameless jump through a function pointer in a temp register
#                   (gcc 2.7.2/2.8.1 has no tail calls; C needs goto* + a register pin)
#   bios-trampoline li $t2,0xA0/0xB0/0xC0; jr $t2; li $t1,N  BIOS call stubs
#   branch-to-next  conditional branch whose target is the instruction right after its
#                   delay slot (gcc's jump pass always deletes such branches)
#   store-ra        stores $ra (or $sp/$gp) to memory outside its own frame
#   ra-in-temp      copies $ra into a temp register and returns through it after calls
#                   (C keeps $ra across calls only in its stack frame)
#   at-as-gpr       computes in the assembler temporary $at (gcc never allocates $1)
#   custom-abi      reads $t*/$v* on entry before writing them and is reached only from
#                   hand-written code (C callers never pass values in those registers)
#   falls-through   has no return and runs into the next hand-written function
# GTE (cop2) use alone is NOT evidence: C reaches it through inline macros.
# Format: <function> <evidence>[,<evidence>...]
